## 2. Bugs found by testing and fixed (all re-tested)

| # | Found by | Bug | Impact | Fix |
|---|---|---|---|---|
| 1 | Unit | Footer notes ("Los precios pueden variar…") parsed as a product | Phantom "no price" rows | Skip rows with text in code column but no price and no description |
| 2 | Unit | `roundUpTo(1700.0000001, 50)` → 1750 (float noise) | Prices jump a whole step | Round the quotient before `ceil` |
| 3 | Integration | 1-cent differences (store's old rounding) shown as "changes" | Noise; unchanged items re-priced/rounded | ≤1 cent = unchanged; keep current price as is |
| 4 | Integration | Manual links not remembered when the linked item had no price change | User re-links every month | Save links for all manual rows on apply |
| 5 | E2E | Creating a peso supplier failed: empty "cotización" was required | Blocked onboarding step 3 | Exchange rate optional unless USD |
| 6 | Review | "1.540" typed as exchange rate parsed as 1.54 | USD lists priced 1000× too low | All form numbers use the AR-aware parser |
| 7 | E2E | Rate limit (5 signups/h/IP) blocks shared IPs (office NAT, tests) | Lost signups | Configurable, default 10/h |
| 8 | Visual review | Review table: action column off-screen at 1366 px; 2 of 10 columns visible on phones | Core screen unusable on mobile | 6 compact columns; card layout < 720 px |
| 9 | Visual review | Raw list prices shown as `39806.54` | Confusing | es-AR formatting, `US$` prefix |
| 10 | a11y (axe) | Scrollable tables not keyboard-focusable (serious) | Keyboard users can't scroll tables | `tabindex=0`, `role=region`, label |
| 11 | Integration | Price column with "Consultar" cells not detected → cover sheet chosen | First upload fails for common lists | Header-matched price column accepted at ≥50% numeric; better sheet scoring |
| 12 | Security review | Worker-less parsing blocked the event loop 1–4 s; PDF spike ~730 MB | One upload slows/crashes everyone | Worker threads, 768 MB cap, 30 s timeout, concurrency 2 |
| 13 | Security review | Small xlsx could declare GBs uncompressed (zip bomb) | OOM | Central-directory size check (250 MB / 5000 entries) |
| 14 | Product review | Plans promised 3/10 users but there was no way to invite | Broken promise | Team invites by one-time link, seat limits enforced |

## 4. Not tested (honest gaps)
- Real supplier files from real Argentine suppliers (only synthetic ones modelled on reported formats). **Top QA priority for the pilot (05, Test C).**
- Import of the exported CSV into specific POS systems (Tango, etc.) — formats are configurable but untested against real POS importers.
- Safari/iOS and Firefox (only Chromium was available).
- Printing labels on physical label sheets (layout is 63.5×38.1 mm, 3×7; alignment on a real printer untested).
- Email delivery (no Resend account here).
- Load with many concurrent users (single-user benchmarks only, see 13).
